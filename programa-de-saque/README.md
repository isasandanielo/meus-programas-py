# Programa de Saque

Programa desenvolvido em Python que simula um saque bancário, calculando automaticamente a quantidade de cédulas necessárias para atingir o valor solicitado.

## Tecnologias utilizadas
- Python

## Funcionamento
O usuário informa o valor que deseja sacar e o programa calcula a quantidade de notas de R$ 50, R$ 20, R$ 10 e R$ 1 necessárias.

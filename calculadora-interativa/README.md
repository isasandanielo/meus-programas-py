# Calculadora Interativa

Programa desenvolvido em Python que permite realizar operações matemáticas entre dois números por meio de um menu interativo.

O usuário pode escolher diferentes operações, atualizar os valores informados e continuar utilizando o programa até selecionar a opção de saída.

## Funcionalidades

- Soma de dois números.
- Multiplicação de dois números.
- Identificação do maior número.
- Verificação se os números são iguais.
- Possibilidade de informar novos números sem reiniciar o programa.
- Menu interativo com opções de operações.
- Encerramento do programa por meio da opção de saída.

## Tecnologias utilizadas

- Python 3.10 ou superior.

## Conceitos praticados

- Estrutura de repetição (`while`).
- Estrutura de seleção múltipla (`match/case`).
- Estruturas condicionais (`if`, `elif` e `else`).
- Variáveis e operadores aritméticos.
- Entrada e saída de dados.
- Construção de menus interativos.

## Como executar

1. Certifique-se de ter o Python 3.10 ou superior instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do programa.
4. Execute o comando:

```bash
python calculadora-interativa.py
```

## Objetivo do projeto

Este projeto faz parte da minha jornada de aprendizado em Python, com foco no desenvolvimento da lógica de programação e na aplicação prática de estruturas de repetição, seleção e operações matemáticas.

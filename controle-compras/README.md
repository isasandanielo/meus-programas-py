# Controle de Compras em Python

## Sobre o projeto

O **Controle de Compras** é um programa desenvolvido em Python que permite registrar produtos e seus respectivos preços, realizando automaticamente cálculos e análises sobre os itens cadastrados.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais da linguagem Python, especialmente estruturas de repetição, estruturas condicionais e manipulação de variáveis.

## Funcionalidades

- Cadastro do nome e preço dos produtos.
- Soma automática dos valores dos produtos registrados.
- Contagem de produtos com preço superior a R$ 1.000,00.
- Identificação do produto mais barato.
- Validação da resposta do usuário para continuar ou encerrar o cadastro.

## Tecnologias utilizadas

- **Python 3**

## Conceitos aplicados

- Variáveis e atribuição de valores.
- Estrutura de repetição `while`.
- Estruturas condicionais `if` e `break`.
- Validação de entradas com `while`.
- Manipulação de strings com `upper()` e fatiamento.
- Operações matemáticas e comparações.

## Como executar

1. Certifique-se de ter o Python 3 instalado.
2. Faça o download ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```bash
python controle-compras.py
```

## Exemplo de utilização

O programa solicita o nome e o preço de cada produto e pergunta se o usuário deseja continuar cadastrando.

Ao finalizar, apresenta três informações:

- Total gasto na compra.
- Quantidade de produtos acima de R$ 1.000,00.
- Nome do produto mais barato registrado.

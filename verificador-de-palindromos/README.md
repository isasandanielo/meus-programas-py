# Verificador de Palíndromos

Programa desenvolvido em Python que verifica se uma frase é um palíndromo, ou seja, se pode ser lida da mesma forma de trás para frente.

O programa remove os espaços, converte todos os caracteres para letras maiúsculas e compara a frase original com sua versão invertida.

## Funcionalidades

- Recebimento de uma frase digitada pelo usuário.
- Remoção dos espaços da frase.
- Conversão dos caracteres para letras maiúsculas.
- Inversão da sequência de caracteres.
- Verificação se a frase é um palíndromo.
- Exibição do resultado da verificação.

## Tecnologias utilizadas

- Python 3

## Conceitos praticados

- Manipulação de strings.
- Estrutura de repetição (`for`).
- Estrutura condicional (`if` e `else`).
- Concatenação de strings.
- Métodos `replace()` e `upper()`.
- Inversão de strings por meio de iteração.

## Como executar

1. Certifique-se de ter o Python instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do programa.
4. Execute o comando:

```bash
python verificador-de-palindromos.py
```

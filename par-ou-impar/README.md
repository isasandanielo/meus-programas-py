# Jogo de Par ou Ímpar

Jogo desenvolvido em Python no qual o usuário compete contra o computador em partidas de par ou ímpar.

O objetivo é praticar lógica de programação por meio de estruturas condicionais, repetição, validação de entradas e geração de números aleatórios.

## Funcionalidades

- Escolha entre par ou ímpar.
- Digitação de um número entre 1 e 10.
- Geração aleatória de um número pelo computador.
- Cálculo da soma dos números escolhidos.
- Verificação do resultado com base na paridade da soma.
- Contagem de partidas consecutivas vencidas.
- Encerramento automático após a primeira derrota.

## Tecnologias utilizadas

- Python 3
- Biblioteca `random`

## Conceitos praticados

- Estruturas condicionais (`if`, `elif` e `else`).
- Estrutura de repetição (`while`).
- Variáveis e contadores.
- Operadores aritméticos e módulo (`%`).
- Validação de entradas.
- Geração de números aleatórios com `random.randint()`.

## Como executar

1. Certifique-se de ter o Python instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do programa.
4. Execute o comando:

```bash
python par-ou-impar.py
```

Este projeto faz parte da minha jornada de aprendizado em Python, com foco no desenvolvimento da lógica de programação e na aplicação prática de estruturas de controle e recursos da linguagem.

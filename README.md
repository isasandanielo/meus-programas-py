# Meus Programas

Bem-vindo(a) ao meu repositório!

Este espaço reúne programas e pequenos projetos desenvolvidos por mim, utilizando Python e outras tecnologias. O objetivo é colocar em prática os conhecimentos adquiridos em programação, desenvolver o raciocínio lógico e explorar soluções para situações do cotidiano.

## Projetos

| Projeto | Descrição |
|---|---|
| [Programa de Saque](./programa-de-saque/) | Simulação de saque bancário com cálculo e distribuição de cédulas. |
| [Controle de Compras](./controle-compras/) | Cadastro de produtos, cálculo do valor total da compra, identificação de produtos acima de R$ 1.000,00 e do item mais barato. |
| [Cadastro e Estatísticas de Pessoas](./cadastro-estatisticas/) | Cadastro de pessoas, classificação por idade e sexo e geração de estatísticas dos registros. |
| [Jogo de Par ou Ímpar](./par-ou-impar/) | Jogo contra o computador com geração de números aleatórios, cálculo de paridade e contagem de vitórias consecutivas. |

## Tecnologias utilizadas

- Python 3
- Git e GitHub

## Objetivos de aprendizado

- Desenvolver lógica de programação.
- Praticar estruturas condicionais e de repetição.
- Trabalhar com variáveis, operadores e manipulação de dados.
- Desenvolver aplicações práticas utilizando Python.

## Sobre

Este repositório está em constante desenvolvimento e será atualizado conforme novos programas e projetos forem criados, acompanhando minha evolução nos estudos de programação.

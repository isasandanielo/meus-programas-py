# Cadastro e Estatísticas de Pessoas

Programa desenvolvido em Python para cadastrar pessoas e gerar estatísticas com base na idade e no sexo informado.

O objetivo é praticar estruturas de repetição, condicionais, validação de dados e contadores em Python.

## Funcionalidades

- Cadastro de pessoas por meio de informações digitadas pelo usuário.
- Validação do sexo informado (M/F).
- Validação da opção de continuar o cadastro (S/N).
- Contagem de pessoas maiores de idade (18 anos ou mais).
- Contagem de pessoas do sexo masculino.
- Contagem de mulheres com menos de 20 anos.
- Exibição de um resumo estatístico ao finalizar os cadastros.

## Tecnologias utilizadas

- Python 3

## Conceitos praticados

- Estruturas condicionais (`if` e `else`).
- Estrutura de repetição (`while`).
- Variáveis e operadores lógicos.
- Contadores.
- Validação de entradas.
- Manipulação de strings com `upper()` e fatiamento.

## Como executar

1. Certifique-se de ter o Python instalado.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do programa.
4. Execute o comando:

```bash
python cadastro-estatisticas.py
```
